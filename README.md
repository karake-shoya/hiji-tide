# 日出の潮

大分県日出町（別府湾）の潮見表と、潮の動き・マズメから割り出した釣りどきを表示するページ。
釣りを始めたばかりの人が、スマホ1枚で「いま行っていいか」「今日はいつ行くか」を決められることを目指している。

- 潮位は海上保安庁が公開する大分験潮所の潮汐調和定数（27分潮）からブラウザ内で推算。
- 日の出／日の入り、月齢、潮回りも同ページ内で計算。外部への問い合わせはない。
- 風・天気とニュースだけ外部から取る（下記）。潮汐はそれらが落ちていても必ず表示する。
- ビルド不要・依存パッケージゼロ。`package.json` は置かない。

本番 https://hiji-tide.vercel.app/

## 使い方

**下部に5つのタブ、上部に日付。** 日付はスクロールしても上に残り、どのタブでも効く。

| タブ | 中身 |
|---|---|
| 🌊 潮 | いま行くべきか・潮位カーブ・釣りどき・天気・満干潮 |
| 📅 週 | 表示中の日から7日ぶんの、その日いちばんの釣りどき |
| 📝 釣果 | 表示中の日の釣行メモ。書いておくと同じ潮回りの日に思い出せる |
| 🐟 魚 | 月ごとの対象魚。月は日付に追随し、手でも選べる |
| ☰ その他 | 持ち物チェック・用語の説明・このサイトについて・画面の明るさ |

- 日付の真ん中をタップするとカレンダーが出る。
- `?d=YYYY-MM-DD` で日付を指定して開ける（例：`/?d=2026-09-28`）。日付を切り替えると URL も追随する。
  書式の違う値や存在しない日付（`2026-02-31` 等）は今日に戻す。
- `?log=1` で開くと釣果タブから始まる（ホーム画面のショートカットから使う）。
- 画面のことば（上げ5分・マズメ・干満差など）はタップすると説明が下から出る。
- タブと、その上に開くパネルは履歴を1つ積む。Android の戻るボタンとスワイプバックで1つ前に戻れる。
- 日中の屋外向けに「明るい」表示へ切り替えられる。選択は端末に残る。

## 潮タブの並び

上から順に、判断に要る順で並べてある。

1. **いま行くべきか** — 今日を見ているときだけ「いまが釣りどき／もうすぐ／ひと休み」を出す。今日以外は「この日のいちばん」に差し替わる。
2. **今の潮** — 主役は数値ではなく「上げ5分」などの状態。
3. **潮位カーブ** — 指でなぞるとその時刻の潮位が出る。
   🔴 満干潮の時刻は**必ずその点の真上（真下）に置く**。枠に収めるために横へずらすと、隣の極値の時刻に見える。
   はみ出しは左右の余白（ラベルの半幅より広く取ってある）で防ぐ。
4. **この日の釣りどき** — 時間帯と理由、その時間帯の気温・降水確率・風。
5. 天気と風／満潮・干潮／この日のデータ／いま釣れる魚／釣りのニュース。

## 週タブ（この先7日）

「今週いつ行くか」を決めるための一覧。1行＝1日で、日付・干満差・潮回り・強弱バッジと、**その日いちばんの釣りどき1つ**だけを出す。

- 起点は**表示中の日**。日付バーを動かせば一覧の起点も動く。
- 採点は単日とまったく同じ `js/fishing.js` を通す。週のために新しい基準は作っていない。
- 行をタップすると潮タブへ移り、日付バーと `?d=` が追随する。
- 潮位はブラウザ内の推算なので**追加の通信はない**。7日ぶんで 43.5ms（Mac の Chrome で実測。スマホ実機は未計測）。
- **風は出さない。** `js/weather.js` は1日1リクエストの設計で、7日ぶんだと Open-Meteo を7回叩くため。出すなら複数日をまとめて取る関数を足してから。

## 釣りどきの決め方

15分前後の潮位差から流速（cm/時）を求め、日の出・日の入りとの近さ（マズメ）と合わせて時間帯ごとに採点する。

- 流速は **50cm/時を満点とする固定基準**で採点する。その日の中での相対評価ではないので、大潮の日と小潮の日を同じものさしで比べられる。
- 見出し横のバッジはその日の最大流速による3段階。45cm/時以上が「よく動く」、35以上が「ふつう」、それ未満が「静か」。
- 時合が日付をまたぐときは前後2時間まで延ばして出す（`前23:02 – 01:02` の表記）。
- 潮が動かない日は閾値を下げて「いちばんマシな1件」だけを出す（2026年で40日）。
- ⚠ **閾値を下げても0件になる日がある。** 2026年は4月9日の1日だけで、0.42 以上の区間は3本あるがどれも34分しか続かず「40分以上」の条件に届かない。画面はこの日に空の文面を出す。
- 「いま行くべきか」は新しい基準を作らず、この採点結果と区間をそのまま3段階に落としている。

## 風と天気

[Open-Meteo](https://open-meteo.com/) から表示中の日の風速・風向・突風・気温・降水確率・天気を取り、3時間ごとに出す。釣りどきの各時間帯にも平均を添える。

- 1日ぶんを1リクエストで取る。項目を増やしてもリクエスト数は変わらない。
- 風の単位は m/s。3m/s 以上と5m/s 以上で色を変える。
- **予報のある期間だけ表示する。** 実測では今日から過去93日〜先15日で、範囲外の日は API がエラーを返すのでセクションごと隠す。
- 通信に失敗しても潮汐の表示は止めない。失敗はキャッシュせず、次に開いたとき再試行する。
- 波高は別府湾内が海域モデルの範囲外（全て null）なので扱わない。
- ライセンスは CC BY 4.0。非商用なら1日1万リクエストまで無料で、API キーは要らない。**収益化するときは要見直し。**

## 釣りニュース

[TSURINEWS](https://tsurinews.jp/) と [TSURI HACK](https://tsurihack.com/) の配信フィードから見出しを出す。日付ナビとは連動せず、起動時に1回だけ読む。

- 各サイトから最大4件を取り、日付の新しい順に並べて上位6件を出す（`PER_FEED` / `LIMIT`）。1サイトが一覧を占めないようにするため。
- RSS には CORS ヘッダがなくブラウザから直接読めないため、`api/news.js` が中継する。
- **見出し・日付・原文リンクだけを返す。記事本文（`description` / `content:encoded`）は読み捨てる。**
- リンクは各フィードのドメインのものだけ通す。見出しは `textContent` で入れる。
- 片方のサイトが落ちても、もう片方が取れていれば出す。全滅なら空配列を返し、ページ側はセクションを隠す。
- 元サイトへの負荷を抑えるため `s-maxage=1800` で30分キャッシュする（本番で `x-vercel-cache: HIT` を確認済み）。

### 出典の扱い

TSURI HACK は[著作権ページ](https://tsurihack.com/copyright)で引用の条件を示している。リンクは原則自由・許諾確認不要。引用は「引用部分が従であること」「出典を明記し掲載元へリンクすること」が条件。
本文を持たず、見出し・日付・出典名・元記事リンクだけを出す今の形はこの条件に沿わせている。フィードを増やすときも同じ条件を守る。

## 釣れる魚の情報

`js/data/fish.js` に月別の対象魚を持つ。釣具店や釣り雑誌で一般に言われている時期をまとめた**目安**で、実測値ではない。
⚠ 出典のない断定は書かない。画面にも「目安」と「地域と年で変わる」旨を必ず出す。漁業調整規則の確認も促す。

## 端末に保存するもの

`localStorage` だけを使い、外部へは送らない。プライベートブラウズでは保存に失敗するが、画面は止めない。

| キー | 中身 |
|---|---|
| `hiji.theme` | 画面の明るさ |
| `hiji.gear` | 持ち物チェックの状態と、自分で足した項目 |
| `hiji.logs` | 釣行メモ（日付・釣れたもの・メモ・その日の潮回り） |

釣行メモを残すと、次に同じ潮回りの日を開いたとき「前回の大潮（9月13日）は アジ 12匹 が釣れています」と判定カードの下に出る。

### 書き出しと読み込み

端末を変えると記録は消える。釣果タブの「記録の持ち出し」から、**釣行メモと持ち物を1つの JSON ファイル**に書き出せる。読み込みは同じ画面から。**ファイルはブラウザの中だけで作って読む。外へは送らない。**

```json
{ "app": "hiji-tide", "version": 1, "exportedAt": "...", "logs": { "2026-09-13": { … } }, "gear": { … } }
```

- 🔴 **読み込んだファイルは端末の外から来る。`sanitizeImport()` を通してから保存する。** 日付になっていないキーの記録は捨て、文字列は保存時と同じ上限（釣れたもの120字・メモ600字・持ち物40字）で切り、数値でない値は `null` にする。`app` と `version` が合わないファイルは断る。
- **同じ日付は `savedAt` があとの方を残す。** 複数の端末を行き来しても直近の編集が生きる。持ち物の自作項目は `id` で重複排除する。
- ⚠ `download` 属性を持たないブラウザでは、書き出しを新しいタブで開いて手で保存してもらう形に落ちる。

## オフライン（PWA）

`sw.js` が資産をキャッシュするので、圏外でも潮見表・釣りどき・魚・持ち物・釣行メモが動く。潮位はブラウザ内で計算しているため通信は要らない。天気とニュースは取得できない。

- **ページ本体・`css`・`js`・ニュース・天気はネットワーク優先。** 応答が 2.5秒（`NET_TIMEOUT`）無ければキャッシュで出し、裏の通信はそのまま走らせて控えを新しくする。電波の弱い釣り場でも待たされず、直したものは次に開いたときそのまま出る。
- アイコンと `manifest` は変わらないのでキャッシュ優先。
- 🔴 **`css/` か `js/` に*ファイルを足したら* `sw.js` の `SHELL` に書き足し、`VERSION` を1つ上げること。** 中身を変えただけなら `VERSION` はそのままでよい。
  書き足しの漏れは `test/shell.test.js` が落とす（`VERSION` の上げ忘れまでは見ていない）。
- ⚠ この形にする前は `css` と `js` もキャッシュ優先だった。直したものが実機に届くまで2〜3回ひらき直す必要があり、実用にならなかった（2026-09-13 に実測）。
- ⚠ ブラウザによってはローカル環境で Service Worker を登録できない。オフライン動作の確認は本番で行う。

## SNS に貼ったときの画像

`icons/og.png`（1200x630）を `og:image` に指定してある。`twitter:card` は `summary_large_image`。

- 絵は `tools/og.html` が正。潮位カーブは 2026年9月13日（大潮・干満差179cm）の**実際の推算**で、金色の帯はその日いちばんの釣りどき（04:44–07:34）。数字を描き変えるときは `js/tide.js` から作り直す。
- PNG は Chrome のヘッドレスで書き出す。依存パッケージは増やさない。

  ```bash
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 --window-size=1200,630 --screenshot=icons/og.png "file://$PWD/tools/og.html"
  ```

- ⚠ **画像を差し替えても SNS 側のキャッシュはすぐには変わらない。** 各社のデバッガで再取得させる。

## 精度

気象庁「潮位表（別府）」との比較で、大潮〜中潮は時刻±10分・潮位±10cm程度。
小潮まわりは満干潮時刻が最大1時間ずれる。

潮回りの名前（大潮・小潮など）は月齢から求めるため、旧暦基準の表記と1日ずれることがある。
名前と実際の干満差が食い違う日もある（長潮のほうが小潮より大きく動く、など）。
強さを見るときは名前より干満差の数値を優先する。

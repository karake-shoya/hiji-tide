# 日出の潮

大分県日出町（別府湾）の潮見表と、潮の動き・マズメから割り出した釣りどきを表示する静的ページ。

- `index.html` 1ファイルのみ。ビルド不要・サーバー不要・外部APIなし。
- 潮位は海上保安庁が公開する大分験潮所の潮汐調和定数（27分潮）からブラウザ内で推算。
- 日の出／日の入り、月齢、潮回りも同ページ内で計算。

## 精度

気象庁「潮位表（別府）」との比較で、大潮〜中潮は時刻±10分・潮位±10cm程度。
小潮まわりは満干潮時刻が最大1時間ずれる。

# 日出の潮

大分県日出町（別府湾）の潮見表と、潮の動き・マズメから割り出した釣りどきを表示する静的ページ。

- 潮位は海上保安庁が公開する大分験潮所の潮汐調和定数（27分潮）からブラウザ内で推算。
- 日の出／日の入り、月齢、潮回りも同ページ内で計算。外部への問い合わせはない。
- 風の予報とニュースだけ外部から取る（下記）。潮汐はそれらが落ちていても必ず表示する。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ全体。ビルド不要・依存パッケージなし |
| `api/news.js` | 釣りニュースの RSS を中継する Vercel Function。依存なし |

`package.json` は置かない。Vercel のフレームワークプリセットは Other、ビルドコマンドなし、出力はルート。
`api/` 配下は Vercel が自動で Serverless Function として扱う。

ローカルで確認するときは Function を動かすため `vercel dev` を使う（静的サーバだと `/api/news` が 404 になる）。

```bash
vercel dev --cwd . --listen 4173
```

## 使い方

`?d=YYYY-MM-DD` で日付を指定して開ける（例：`/?d=2026-09-28`）。
日付を切り替えると URL も追随するので、そのまま共有・ブックマークできる。
書式の違う値や存在しない日付（`2026-02-31` 等）は今日に戻す。

ページ下部の「用語」に、上げ◯分・マズメ・時合・潮回りなどの説明を折りたたみで置いている。

## 釣りどきの決め方

15分前後の潮位差から流速（cm/時）を求め、日の出・日の入りとの近さ（マズメ）と合わせて時間帯ごとに採点する。

- 流速は **50cm/時を満点とする固定基準**で採点する。その日の中での相対評価ではないので、大潮の日と小潮の日を同じものさしで比べられる。
- 見出し横のバッジはその日の最大流速による3段階。45cm/時以上が「よく動く」、35以上が「ふつう」、それ未満が「静か」。
- 時合が日付をまたぐときは前後2時間まで延ばして出す（`前23:02 – 01:02` の表記）。
- 潮が動かない日は閾値を下げて「いちばんマシな1件」だけを出す。

## 風の予報

[Open-Meteo](https://open-meteo.com/) から表示中の日の風速・風向・突風を取り、3時間ごとに出す。釣りどきの各時間帯にも平均風速を添える。

- 単位は m/s。3m/s 以上と5m/s 以上で色を変える。
- **予報のある期間だけ表示する。** 実測では今日から過去93日〜先15日で、範囲外の日は API がエラーを返すのでセクションごと隠す。
- 通信に失敗しても潮汐の表示は止めない。失敗はキャッシュせず、次に開いたとき再試行する。
- 波高は別府湾内が海域モデルの範囲外（全て null）なので扱わない。
- ライセンスは CC BY 4.0。非商用なら1日1万リクエストまで無料で、API キーは要らない。**収益化するときは要見直し。**

## 釣りニュース

[TSURINEWS](https://tsurinews.jp/) の配信フィードから見出し5件を出す。日付ナビとは連動せず、起動時に1回だけ読む。

- RSS には CORS ヘッダがなくブラウザから直接読めないため、`api/news.js` が中継する。
- **見出し・日付・原文リンクだけを返す。記事本文（`description` / `content:encoded`）は読み捨てる。**
- リンクは `tsurinews.jp` のものだけ通す。見出しは `textContent` で入れる。
- 元サイトへの負荷を抑えるため `s-maxage=1800` で30分キャッシュする。
- 取得に失敗しても 200 と空配列を返し、ページ側はセクションを隠す。

## 精度

気象庁「潮位表（別府）」との比較で、大潮〜中潮は時刻±10分・潮位±10cm程度。
小潮まわりは満干潮時刻が最大1時間ずれる。

潮回りの名前（大潮・小潮など）は月齢から求めるため、旧暦基準の表記と1日ずれることがある。
名前と実際の干満差が食い違う日もある（長潮のほうが小潮より大きく動く、など）。
強さを見るときは名前より干満差の数値を優先する。
